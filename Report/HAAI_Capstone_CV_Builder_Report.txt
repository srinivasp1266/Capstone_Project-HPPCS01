ABSTRACT

This project presents a Multi-LLM CV Builder application that leverages two specialized Large Language Models for enhanced CV creation and tailoring. The system employs Gemma 2B for fast content generation and Llama2 7B for advanced data analysis, creating a synergistic architecture that optimizes both performance and quality for professional resume generation. The implementation follows HAAI++ requirements with all files in a single directory structure.

1. INTRODUCTION

The modern job market demands tailored, ATS-optimized resumes that effectively match candidate profiles with specific job requirements. Traditional CV creation methods lack the intelligence to automatically adapt content for different positions and industries. This project addresses these challenges by implementing a dual-LLM architecture that combines the strengths of two specialized models to create superior CV tailoring capabilities.

The system transforms unstructured user profile data into professional, tailored CVs through intelligent content generation and analytical requirement matching. By utilizing multiple LLMs with distinct specializations, the application achieves better performance than single-model approaches while satisfying HAAI++ capstone requirements for multi-LLM implementation.

2. METHODOLOGY

2.1 Multi-LLM Architecture Design

The system implements a task-specific dual-model architecture:

Model 1 - Gemma 2B (Content Generation Specialist):
- Primary Role: Creative content generation and professional writing
- Justification: Optimized for fast response times and creative writing tasks. The 2B parameter size provides excellent performance-to-efficiency ratio for content generation while maintaining lower computational overhead for real-time user interactions.
- Specializations: Professional summary creation, experience description enhancement, project description tailoring
- Configuration: Temperature 0.7 for creative output, 1024 token limit

Model 2 - Llama2 7B (Data Analysis Specialist):
- Primary Role: Advanced analytical processing and requirement matching
- Justification: Larger parameter count enables superior analytical capabilities, complex reasoning, and structured data processing. Better performance on analytical tasks requiring deep understanding of job requirements and candidate qualifications.
- Specializations: ATS optimization, keyword analysis, requirement matching, structured data extraction
- Configuration: Temperature 0.1 for precise analysis, 2048 token limit

2.2 Task Routing System

The MultiLLMService implements intelligent task routing based on operation type:
- Content Generation Tasks → Gemma 2B (professional summaries, experience tailoring, project descriptions)
- Data Analysis Tasks → Llama2 7B (ATS optimization, requirement analysis, keyword matching)
- Structured Extraction Tasks → Llama2 7B (resume parsing, job requirement extraction)

2.3 System Components (Flattened Architecture)

All components are implemented as individual Python modules in the same directory per HAAI++ requirements:
- multi_llm_service.py: Orchestrates dual-model operations with task-specific routing
- cv_generator.py: Manages CV optimization using both models collaboratively
- document_generator.py: Creates professional HTML output with modern styling
- resume_parser.py: Extracts structured data from unstructured input using analytical model
- job_parser.py: Analyzes job requirements using advanced reasoning capabilities
- app.py: Streamlit web interface for user interaction
- main.py: Entry point with command-line argument support
